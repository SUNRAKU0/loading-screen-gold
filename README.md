One sharp loading-screen tip for stressed developers and AI coding agents — an entry for make.fun's **Loading Screen Gold: A Tip in 200 Characters** bounty.

The program writes one line (under 200 characters) to `/output/entry.txt`:

> Tip: the loading bar is not stuck. It is thinking about everything you did wrong, one file at a time.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network, deterministic.
